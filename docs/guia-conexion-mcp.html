DrawDB Protocol Suite

Guía de Integración Servidor MCP

Conexión de Model Context Protocol (MCP) con OpenClaw, Cline CLI, Claude Desktop/Code, ChatGPT y Codex

1. Introducción y Arquitectura

El servidor DrawDB MCP expone un conjunto de herramientas estandarizadas mediante el protocolo Model Context Protocol (MCP). Permite a asistentes y agentes de inteligencia artificial consultar la estructura del diagrama, navegar tablas en grafos relacionales, exportar DDL SQL y aplicar modificaciones atómicas en tiempo real sincronizadas mediante WebSockets hacia los clientes de DrawDB en el navegador.

Punto de Conexión Unificado:
• Local (DDEV): https://drawdb-server.ddev.site/api/mcp
• Producción: https://<tu-dominio-backend>/api/mcp
• Transportes soportados: Streamable HTTP (JSON-RPC 2.0 unificado) y Server-Sent Events (SSE).

2. Obtención de Credenciales (API Token)

  1. Inicia sesión en la plataforma web de DrawDB (https://drawdb.ddev.site o tu URL en producción).
  2. Navega al menú de usuario en la esquina superior derecha y selecciona Mi Cuenta (/account).
  3. En la sección Tokens de acceso MCP (Agentes), haz clic en Nuevo token MCP.
  4. Asigna un nombre descriptivo (ej. OpenClaw Agent, Cline CLI o Claude Desktop) y selecciona el alcance:
    • Lectura y escritura (write): Permite consultar el diagrama, crear/editar tablas, columnas y relaciones.
    • Solo lectura (read): Restringe al agente exclusivamente a consultar esquemas, generar resúmenes y exportar DDL.
  5. Copia el token generado (formato ddb_mcp_...). Por motivos de seguridad, este token solo se muestra una vez.

3. Catálogo de Herramientas (Tools) Disponibles

Herramienta Tipo Descripción
list_projects Lectura Lista los proyectos y diagramas disponibles con ID, nombre, motor de DB y conteo de tablas.
get_schema_summary Lectura Genera un resumen ultra-compacto del diagrama o un esquema visual en Mermaid ERD sin coordenadas visuales para ahorro de tokens.
get_diagram Lectura Devuelve la estructura completa del diagrama en JSON.
search_tables Lectura Búsqueda semántica y paginada de tablas, columnas y relaciones vecinas en esquemas grandes.
create_table Escritura Crea una nueva tabla validando tipos según el motor. Calcula coordenadas automáticas y difunde en vivo.
update_table Escritura Modifica columnas, tipos, comentarios o índices. Permite búsqueda por nombre o ID.
delete_table Escritura Elimina una tabla con soporte opcional de borrado en cascada de sus Foreign Keys.
create_relationship Escritura Crea llaves foráneas y relaciones 1:1, 1:N o N:M entre tablas existentes.
delete_relationship Escritura Elimina una relación específica por su ID.
export_sql Lectura Genera el script DDL SQL completo para PostgreSQL, MySQL, MariaDB, SQLite, MSSQL u Oracle.

4. Configuración por Cliente / Asistente IA

A. OpenClaw (Asistente & Agentes Especialistas)

En OpenClaw puedes conectar el servidor MCP de tres maneras equivalentes:

Opción 1: Mediante la CLI de OpenClaw

openclaw mcp add drawdb \
  --url https://drawdb-server.ddev.site/api/mcp \
  --transport streamable-http \
  --header "Authorization: Bearer ddb_mcp_TU_TOKEN_AQUI"

# Verificar la conexión y probar las herramientas expuestas:
openclaw mcp doctor drawdb --probe

Opción 2: Desde el archivo de configuración ~/.openclaw/openclaw.json

En el bloque mcp.servers añade la definición:

{
  "mcp": {
    "servers": {
      "drawdb": {
        "url": "https://drawdb-server.ddev.site/api/mcp",
        "transport": "streamable-http",
        "enabled": true,
        "headers": {
          "Authorization": "Bearer ddb_mcp_TU_TOKEN_AQUI"
        }
      }
    }
  }
}

Opción 3: Desde la interfaz web (Control UI de OpenClaw)

  • Ve a Settings → MCP y pulsa en Add server.
  • Nombre: drawdb. Transporte: Streamable HTTP.
  • URL: https://drawdb-server.ddev.site/api/mcp (o tu URL en producción).
  • En la cabecera HTTP ingresa: Authorization: Bearer ddb_mcp_TU_TOKEN_AQUI.

B. Cline CLI / Extensión VS Code

En Cline, agrega la configuración en el archivo cline_mcp_settings.json: 

{
  "mcpServers": {
    "drawdb": {
      "url": "https://drawdb-server.ddev.site/api/mcp",
      "headers": {
        "Authorization": "Bearer ddb_mcp_TU_TOKEN_AQUI"
      }
    }
  }
}

C. Claude Desktop / Claude Code CLI

En Claude Desktop, abre la configuración desde Settings > Developer > Edit Config (archivo claude_desktop_config.json): 

{
  "mcpServers": {
    "drawdb": {
      "url": "https://drawdb-server.ddev.site/api/mcp",
      "headers": {
        "Authorization": "Bearer ddb_mcp_TU_TOKEN_AQUI"
      }
    }
  }
}

Para Claude Code (CLI), puedes registrar el servidor directamente con el comando: 

claude mcp add --transport http drawdb \
  https://drawdb-server.ddev.site/api/mcp \
  --header "Authorization: Bearer ddb_mcp_TU_TOKEN_AQUI"

D. ChatGPT (OpenAI Custom GPTs & Actions)

ChatGPT interactúa con APIs externas a través de Custom Actions (OpenAPI / GPTs) o puentes compatibles con MCP:

  • En la configuración de tu Custom GPT, dirígete a Actions > Create new action.
  • En el tipo de autenticación, selecciona API Key con formato Bearer e ingresa tu token ddb_mcp_....
  • En el endpoint de llamadas, configura el proxy JSON-RPC o importa la especificación OpenAPI que expone las tools bajo /api/mcp.
  • Si utilizas un puente local como mcp-proxy, configúralo como servicio upstream con la URL y cabeceras correspondientes.

E. OpenAI Codex / IDE Extensions (Cursor, Windsurf)

Tanto en Cursor (archivo ~/.cursor/mcp.json) como en Windsurf o extensiones de Codex, la declaración estándar es:

  "mcpServers": {
    "drawdb": {
      "url": "https://drawdb-server.ddev.site/api/mcp",
      "headers": {
        "Authorization": "Bearer ddb_mcp_TU_TOKEN_AQUI"
      }
    }
  }
}

5. Ejemplos de Prompts para Interactuar con DrawDB

Sugerencia de Flujo de Trabajo: Siempre pide al agente que comience consultando con get_schema_summary para obtener contexto del esquema sin saturar su ventana de contexto.

Ejemplo 1: Análisis y Consulta de Esquema

"Consulta con la herramienta get_schema_summary el proyecto 'Clínica Médica' y muéstrame el diagrama de relaciones en formato Mermaid."

Ejemplo 2: Creación de Nuevas Entidades Relacionadas

"Usa el servidor MCP de DrawDB en el proyecto actual para agregar una tabla 'citas_medicas' con campos id (uuid pk), doctor_id (uuid), paciente_id (uuid) y fecha (timestamptz). Luego crea la relación hacia la tabla 'pacientes'."

Ejemplo 3: Generación de Migraciones SQL

"Invoca export_sql con dialecto 'postgresql' para el proyecto 'Clínica Médica' y genera el archivo de migración listo para mi backend."

6. Seguridad y Rollback

  • Control de Versiones y Snapshots: Cada mutación ejecutada por un agente vía MCP genera automáticamente un punto de restauración previo en la base de datos bajo el autor [Nombre] (MCP).
  • Rollback en 1 Clic: Si un agente comete un error en el modelado, abre el panel de Historial en la interfaz web de DrawDB y selecciona Restaurar esta versión.
  • Revocación Inmediata: Si un token es revocado en la pantalla de Mi Cuenta, cualquier llamada en curso o futura por parte de cualquier agente es rechazada al instante con código 401 Unauthorized.
